# exDesktop + iOS Profile V2 (Windows x64)

Автоматическая облачная сборка **exDesktop** с нативным C++/Qt патчем **iOS Profile V2 (Liquid Glass)**.

## Что добавляет патч

- **Адаптивный фон по аватарке** — автоматическое извлечение палитры из фото профиля, если не задан цвет профиля Telegram.
- **Интерактивные 3D-пузырьки подарков** — кристальное стекло / матовое стекло / мягкое свечение, независимая 2D-физика (можно схватить, потянуть с желе-растяжением и бросить — отскакивают от стенок, аватарки и друг от друга; короткий клик открывает подарок).
- **Свечение края аватарки** — цветная подсветка контура аватарки от ближайших подарков в реальном времени.
- **Круглые стеклянные кнопки действий** и стеклянные блики на плашках баланса и карточке музыки.
- **Пульсация в ритм музыки** — синхронизация с встроенным плеером Telegram Desktop.
- **Настройки без перезапуска** — `Настройки exDesktop → Основные → iOS Profile V2`.

## Первый запуск сборки (1 раз добавить ключи)

1. Получи `api_id` и `api_hash` на https://my.telegram.org (раздел **API development tools**).
2. Открой **Settings → Secrets and variables → Actions** этого репозитория и добавь два секрета:
   - `TDESKTOP_API_ID`
   - `TDESKTOP_API_HASH`

## Как собрать новую версию в 1 клик

1. Открой вкладку **Actions → Build Patched exDesktop (Windows x64) → Run workflow**.
2. Оставь галочки:
   - `sync_upstream = true` — автоматически подтянет последнюю версию `metawka/exDesktop` и накатит поверх `patches/ios_profile_v2.patch`.
   - `publish_release = true` — выложит готовый `.zip` прямо в раздел **Releases**.
3. Скачай готовый `exDesktop-win64-profile-v2-*.zip` из **Releases** (или из **Artifacts** запуска), распакуй и запусти `exDesktop.exe`.

> Первый запуск собирает зависимости Qt6/WebRTC с нуля и кеширует их в GitHub Actions (занимает ~1.5–3 часа). Все последующие обновления собираются из кеша значительно быстрее.
